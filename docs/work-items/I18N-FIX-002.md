## Four traps this session hit, do not repeat them

1. **A D-number reservation goes stale the moment another branch merges.** Four
   collisions had to be resolved by hand on 7 August. Grepping every branch before
   reserving is not enough; re-check before opening the pull request **and before
   pushing a fix onto an open one**. D-max was D085 across all branches when this
   document was written.
2. **Work-item IDs collide the same way.** Two sessions created a `SITE-FIX-008`
   the same day for unrelated defects.
3. **A merge can land while you are still working.** PR #29 was merged at 18:30
   and a round-2 commit pushed at 18:34 never reached the integration branch.
   Check the PR state before pushing.
4. **Chrome's window floor is 500px** (D034). A plain resize reports a "360px"
   measurement that really rendered at 500. Use
   `Emulation.setDeviceMetricsOverride`.

# UI-004 - Adopt the improved logomark from the design project

- **Type**: STORY
- **Branch**: `feat/logo-maquette`
- **Base**: `refonte-multipages`
- **Decisions**: D086, D087, D088, D089
- **Date**: 2026-08-07

## Context

The founder reworked the ALTARYS LABS logomark in the claude.ai/design project
`53d1c228-d274-4df3-8022-1a427dd96c15` and handed off `Header.dc.html`, then
`Footer.dc.html`. Both were read live through `DesignSync`, after the founder's
edits, not from the dated snapshot in `docs/vitrine/refonte/prototypes/`.

The change is not cosmetic. The old lockup was one SVG on a `0 0 300 72`
viewBox, rendered at 160px in the header and 150px in the footer. Every value
written in that file was therefore scaled by 0.53 and by 0.5:

| element | written | header | footer |
|---|---|---|---|
| `ALTARYS` | 27 | 14.4px | 13.5px |
| `LABS` | 9.5 | **5.06px** | **4.75px** |
| diamond outline | 1.5 | 0.8px | 0.75px |

Reading the source, those values look right. That is why the defect survived
this long. Moving the wordmark to real HTML text makes the written size the
rendered size.

## Acceptance criteria

1. The header logo reproduces `Header.dc.html`: diamond 30x28 at the maquette's
   stroke weights, `ALTARYS` in DM Sans 600 / 15px / 3px tracking in
   `--navy-text` (the prototypes write 700, which no loaded face can satisfy;
   see D089), `LABS` in Space Mono 700 / 9.5px / 4px tracking in
   `--gold-deeper`, 10px gutter.
2. The footer logo reproduces `Footer.dc.html`: same diamond stripped of its
   vertex dots and inner facet at 28x26, inline wordmark, `ALTARYS` in DM Sans
   600 / 14.5px / 2.5px in `--ivory`, `LABS` in Space Mono 700 / 10px / 3px in
   `--gold-light`. No page shows two diamond weights.
3. `public/assets/favicon.svg` carries the new geometry with nothing clipped by
   its viewBox, and no route, dictionary key or SEO tag changes.
4. `npm run build` and `npm run check` are green, and contrast holds AA on both
   surfaces.

## Notes

- `--gutter` drops to 20px below 520px, leaving 320px of usable width at 360px
  for a logo of roughly 126px and a 44px hamburger. No mobile size reduction was
  needed, so none was added.
- The space between `ALTARYS` and `LABS` is a real text node, not a margin, so a
  screen reader hears two words. In the stacked lockup the container is a flex
  box, which ignores whitespace-only text nodes, so it does not create a third
  line.
- D084 and D085 were already reserved by `SITE-FIX-006` on the open branch
  `fix/procedure-de-revue`. This item takes D086 to D088.
